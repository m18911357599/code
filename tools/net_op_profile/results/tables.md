## 实测环境

- PyTorch `2.13.0+cpu` / torchvision `0.28.0+cpu` / 设备 `cpu`
- 线程数 `4`；`inference_mode` + `eval`；随机权重（结构与量级与预训练一致）
- **调用次数**取 ATen 叶子（同 Pattern 子调用不重复计）；**耗时**为排他 CPU self-time
- **FLOPs** 对卷积/GEMM/SDPA 按 MAC×2 估算，仅计叶子，避免 `conv2d→convolution→mkldnn` 三计
- CPU 时间份额**不能**直接当 GPU/NPU 份额；FLOPs 与调用次数跨设备更稳
