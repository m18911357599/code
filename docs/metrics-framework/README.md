## 三代在答什么问题

```text
G0  这个 Pattern 好不好写？          → 专家档位（不可复现）
G1  打到 60/90/99% 峰值时好不好用？ → 加权总分 U_p（公式与表不一致）
G2  为正确性必须多写多少软件税？    → ΔS-LOC 等计数（最可操作）
G3  芯片+编译器+工具链好不好用？    → 七章问卷式方案（权重自洽，口径变粗）
```

它们**不是同一套指标换封面**。G0 测的是算法–ISA 亲和；G2 测的是软件制品上的税；G1/G3 测的是「易用性画像」，但维度切法、红线政策、分值语义都不同。

## 结论（先看这个）

1. **没有一份已经落地的 `metrics-framework` 实现**。只有文档；没有冻结套件、AST 规则版本、采集脚本或台账。
2. **G1 的档位权重表不能按正文公式复现。** 60% 档五个 $\Omega_{p,d}$ 加起来是 **0.795**，不是 1；按 $\Omega_{p,d}=\alpha_{p,d}\Omega_d/\sum\alpha\Omega$ 算出的 60% 权重与表差最大 0.101。
3. **G1 维度 A 权重不闭合。** 声称 18 项且 $\sum W_{A,j}=1$，§7 列出 16 项只加到 **0.86**；A7 与「其余项」还重复计了自动同步 / tiling / 格式转换。
4. **G1 红线编号与单位混用。** 「错误遥测覆盖率」标成 C1，正文 C1 是性能度量覆盖、C4 才是错误遥测；门槛有的用分数（≥80）、有的用原始率（100%）、有的用定性（核级复位可用）。
5. **G3 把跨代项写进 S1，但权重是 100% / 0% / 0%。** 源码可移植、跨代性能达成率在表里存在，却不进 $U_p$。红线从 G1 的 $\min(U_p,59)$ 改成 $U_p^{*}=0$，同一缺陷的惩罚差一个等级档。
6. **G2 是目前唯一给出操作定义的一层**（INCLUDE/EXCLUDE、基线 B-SIMT、`rule_ver`）。它不覆盖调试可观测与代际契约；不能单独替代 G1/G3。
7. **三套分数禁止横比、禁止加总。** 要对齐，必须先统一：观测层、义务（正确性 vs 性能）、基线、红线政策，再映射维度。

## 建议的统一落点

最小可用框架（不引入新的主观档）：

- **计数层用 G2**：先落地 S-LOC / ΔS-LOC / Tail-LOC / Cover / Gap-I / Space-N / Pipe-Stage。
- **画像层用修订后的 G1 公式**：修权重闭合与 $\Omega_{p,d}$ 表，红线单位全部改成「归一化分 + 明确 $T_r$」。
- **章节导航用 G3 的 `Sx-Dy` 标题**，但每条 `Sx-Dy` 必须能指回一个 G2 六轴点或一条 G1 指标，禁止只写「方案介绍」。
- **G0 的亲/偏/难只允许事后映射**，与 G2 §3.4 一致，不参与计算。

未合入的 PR #12 / #13 不要直接当现行标准；`main` 上仍以 G1 长文为准，G3 若合入会把该长文收成指针。
